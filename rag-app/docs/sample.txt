Acme Corporation Security Policy — Internal Use Only

1. Access Control
   Employees must use MFA for all internal systems. Shared passwords are prohibited.
   Service accounts require approval from the CISO before provisioning.

2. Data Classification
   Confidential: customer PII, financial records, source code.
   Internal: operational documents, project plans.
   Public: press releases, public documentation.

3. Incident Response
   Report suspected incidents to security@acme.example within 1 hour of discovery.
   Do not attempt containment without guidance from the security team.

4. AI System Usage
   Employees may not input confidential data into external AI services without written approval.
   All internal AI systems must be reviewed by the security team before production deployment.
